# Exercise 3 - Stored Procedures

## Objective

Implement PL/SQL stored procedures for common banking operations.

## Scenarios

### Scenario 1
Process monthly interest for all savings accounts.

### Scenario 2
Update employee salaries by applying a bonus percentage to a specified department.

### Scenario 3
Transfer funds between two bank accounts after validating sufficient balance.

## Tools Used

- Oracle Live SQL
- Oracle PL/SQL
- Visual Studio Code
- Git & GitHub
